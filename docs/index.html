02

Quick start快速开始

macOS · Linux
git clone https://github.com/Arcadia-1/virtuoso-bridge-lite.git
cd virtuoso-bridge-lite
uv venv .venv && source .venv/bin/activate
uv pip install -e .

virtuoso-bridge init user@host   # write ~/.virtuoso-bridge/.env
virtuoso-bridge start            # SSH tunnel + daemon files
virtuoso-bridge status           # prints the load("...") line for your CIW
virtuoso-bridge eval '1+2'       # after loading it: 3

Paste the load("...") line into the Virtuoso CIW you want to drive. Windows, local mode and standalone Spectre: see the guide.把 load("...") 这行粘贴到要控制的 Virtuoso CIW。Windows、本机模式、独立 Spectre 见使用文档。

Architecture架构

  • VirtuosoClient: a plain TCP SKILL client. Sends SKILL as JSON and gets results; it knows nothing about SSH.VirtuosoClient：纯 TCP 的 SKILL 客户端，以 JSON 发送 SKILL 并取回结果，不关心 SSH。
  • SpectreSimulator: runs standalone Spectre locally or over SSH and parses PSF ASCII results into Python data.SpectreSimulator：在本机或经 SSH 运行独立 Spectre，把 PSF ASCII 结果解析成 Python 数据。
  • SSHClient: resolves the GUI, deployment, daemon and Spectre host roles, keeps a standalone port forward to the daemon host, and runs role-specific commands and transfers over OpenSSH or Paramiko. Skipped in local mode.SSHClient：解析 GUI、部署、daemon、Spectre 各主机角色，维持到 daemon 主机的独立端口转发，并通过 OpenSSH 或 Paramiko 执行各角色的命令与文件传输。本机模式下不使用。

VirtuosoClient works with any TCP endpoint (SSH tunnel, VPN, LAN or local), and each profile manages its own tunnel to a separate server. To see the raw mechanism, start with ramic_bridge.il and bridge.py.VirtuosoClient 可连接任何 TCP 端点（SSH 隧道、VPN、局域网或本机），每个配置各自管理到一台服务器的隧道。想看底层机制，从 ramic_bridge.il 和 bridge.py 读起。
