Quick start快速开始

Install from source on your machine, then connect to the host that runs Virtuoso.在本机从源码安装，然后连接运行 Virtuoso 的主机。

macOS · Linux
git clone https://github.com/Arcadia-1/virtuoso-bridge-lite.git
cd virtuoso-bridge-lite
uv venv .venv && source .venv/bin/activate
uv pip install -e .

virtuoso-bridge init user@host   # write ~/.virtuoso-bridge/.env
virtuoso-bridge start            # SSH tunnel + daemon files
virtuoso-bridge status           # prints the load("...") line for your CIW
virtuoso-bridge eval '1+2'       # after loading it: 3

Paste the load("...") line shown by status into the Virtuoso CIW you want to drive. Windows, local mode, split hosts and standalone Spectre are covered in the README.把 status 显示的 load("...") 命令粘贴到要控制的 Virtuoso CIW。Windows、本机模式、GUI 与 daemon 分机部署、独立 Spectre 的配置见 README。

From PythonPython 示例

Build an RC network in a new schematic cellview.在新的原理图 cellview 中搭一个 RC 网络。

create_rc.py
from virtuoso_bridge import VirtuosoClient
from virtuoso_bridge.virtuoso.schematic.ops import (
    schematic_create_inst_by_master_name as inst,
    schematic_create_wire_between_instance_terms as wire,
)

client = VirtuosoClient.from_env()
with client.schematic.create("my_lib", "rc_demo") as sch:
    sch.add(inst("analogLib", "res", "symbol", "R0", 0.5, 0.0, "R90"))
    sch.add(inst("analogLib", "cap", "symbol", "C0", 1.5, -0.5, "R0"))
    sch.add(wire("R0", "MINUS", "C0", "PLUS"))
# Leaving the block runs schCheck and saves the cellview.

Full version with pins and a generated symbol: examples/01_virtuoso/symbol.带引脚和自动生成符号的完整版本：examples/01_virtuoso/symbol。
