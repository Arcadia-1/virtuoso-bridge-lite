Choose your execution path.选择你的运行方式。

Virtuoso Bridge is a Python package, not a hosted EDA environment. You supply the Cadence installation, licenses, and any process models your design needs.Virtuoso Bridge 是 Python 软件包，而非托管的 EDA 环境。你需要自行提供 Cadence 安装、许可及设计所需的工艺模型。

  • Python 3.9+ and uv on your client. macOS, Windows, and Linux clients are supported.客户端需安装 Python 3.9+ 和 uv，支持 macOS、Windows 与 Linux。
  • An accessible, running Virtuoso session for SKILL and cellview operations.SKILL 与 cellview 操作需要可访问且已启动的 Virtuoso 会话。
  • For standalone simulation, an accessible Spectre installation and license; a Virtuoso session is not required.独立仿真需要可用的 Spectre 安装与许可，不需要 Virtuoso 会话。

Install from source.从源码安装。

Clone the current repository and install into a virtual environment.克隆当前仓库，并安装到独立虚拟环境中。

macOS / Linux 
git clone https://github.com/Arcadia-1/virtuoso-bridge-lite.git
cd virtuoso-bridge-lite
uv venv .venv
source .venv/bin/activate
uv pip install -e .

On Windows PowerShell, replace the activation command with .\.venv\Scripts\Activate.ps1. Keep the other commands the same.在 Windows PowerShell 中，将激活命令改为 .\.venv\Scripts\Activate.ps1，其余命令不变。

Connect to remote Virtuoso.连接远程 Virtuoso。

Make sure SSH access works and Virtuoso is running on the intended host. Replace user@host with your actual account and EDA host.先确认 SSH 可用，且目标主机上的 Virtuoso 已启动。将 user@host 替换为实际账号与 EDA 主机地址。

CONNECT 
virtuoso-bridge init user@host
virtuoso-bridge start

If your environment needs a jump host, use virtuoso-bridge init user@host -J user@jump-host. The default starter configuration is written to ~/.virtuoso-bridge/.env.若需要跳板机，可使用 virtuoso-bridge init user@host -J user@jump-host。默认初始配置写入 ~/.virtuoso-bridge/.env。

There is one manual CIW step. Copy the exact load(...) command printed by start into the selected Virtuoso CIW. Do not substitute a guessed path or target an unrelated session.这里有一步手动 CIW 操作。把 start 输出的完整 load(...) 命令复制到选定的 Virtuoso CIW。不要猜测路径，也不要操作无关会话。

VERIFY 
virtuoso-bridge status
virtuoso-bridge eval '1+2'

The arithmetic check should report a successful result with output 3. It verifies the SKILL round trip, not an electrical simulation.算术测试应返回成功结果，输出为 3。这验证的是 SKILL 通信链路，而非电路仿真。

For split GUI/daemon hosts or site-specific environments, follow the current connection reference. Multi-host profiles are optional.GUI 与守护进程分属不同主机，或存在站点环境配置时，请参考当前连接文档。多主机配置不是默认前提。

Stay on the same machine.直接使用本机环境。

For a client running on the actual Virtuoso host, set VB_REMOTE_HOST=localhost in the active bridge environment file. Use a configuration for this local session, not a remote profile with conflicting GUI/daemon host roles.若客户端就在 Virtuoso 所在主机上，在当前 Bridge 环境配置文件中设置 VB_REMOTE_HOST=localhost。请使用对应的本机会话配置，避免混入远程 profile 的 GUI 或守护进程主机设置。

Run virtuoso-bridge start, follow its CIW loading instructions, then use the same status and arithmetic checks. Local mode does not need an SSH tunnel.运行 virtuoso-bridge start，按输出完成 CIW 加载，再执行相同的状态与算术测试。本机模式不需要 SSH 隧道。

Python can discover a parent .env and override inherited settings. In an embedded or long-lived process, pin the intended file before creating clients.Python 可能发现上级目录的 .env 并覆盖继承的设置。在嵌入式或长时间运行的进程中，应在创建客户端前指定配置文件。

EXPLICIT CONFIGURATION / Python 
from virtuoso_bridge.env import set_runtime_env_file
from virtuoso_bridge import VirtuosoClient

set_runtime_env_file("/path/to/virtuoso-bridge.env")
client = VirtuosoClient.from_env()
result = client.execute_skill("1+2")

Run Spectre independently.独立运行 Spectre。

Spectre simulation is separate from the Virtuoso SKILL bridge. Configure the intended local or remote execution environment, with spectre on its PATH or a suitable site setup script via VB_CADENCE_CSHRC.Spectre 仿真与 Virtuoso SKILL Bridge 相互独立。配置所需的本地或远程执行环境，确保其 PATH 中包含 spectre，或通过 VB_CADENCE_CSHRC 指定合适的站点环境脚本。

NETLIST SIMULATION / Python 
from pathlib import Path
from virtuoso_bridge.spectre import SpectreSimulator

simulator = SpectreSimulator.from_env(work_dir="output")
result = simulator.run_simulation(Path("tb.scs"))
if not result.ok:
    raise RuntimeError(result.errors)
print(result.metadata["output_dir"])

Provide your own valid testbench and model references. See the Spectre examples for transient, AC, periodic analysis, and parallel sweeps, and the Spectre skill for setup and PSF reading.需提供有效的测试网表与模型引用。瞬态、AC、周期分析与并行扫描可参考 Spectre 示例，环境配置与 PSF 读取可参考 Spectre 技能文档。

Before you go further.继续之前，你可能想知道。

Does Bridge replace Cadence or provide a PDK?Bridge 会替代 Cadence，或提供 PDK 吗？

No. It provides programmatic access to an existing environment. Cadence licenses, PDK access and their terms remain your responsibility.不会。它为已有环境提供可编程访问。Cadence 许可、PDK 访问权限及相关使用条款，仍由你自行管理。

Do I have to configure multiple servers or profiles?必须配置多个服务器或 profile 吗？

No. The one-host configuration is sufficient. Multi-server, multi-account and process configurations are optional extensions.不需要。一台主机的配置就足够。多服务器、多账号和工艺配置均为可选扩展。

Are the homepage waveforms real measured results?首页的波形是实测结果吗？

No. Homepage graphics are labeled workflow illustrations. The code links point to real implementation and examples; run a suitable testbench in your environment to obtain actual results.不是。首页图形均标明为流程示意。代码链接指向实际实现和示例；真实结果需在你自己的环境中运行合适的测试网表获得。

What if a simulation request times out or a CIW dialog appears?请求超时或 CIW 弹出对话框时怎么办？

An uncertain acknowledgement is not proof that a request failed. Keep the request or job handle, inspect the original outcome, and avoid blind retries. Treat shared CIWs as user-owned. Read the shared-CIW protection guide before enabling its optional guard.确认信息不明确，不代表请求已经失败。保留请求或任务标识，核对原始结果，避免盲目重试。共享 CIW 属于用户控制；开启可选保护前，请阅读共享 CIW 保护指南。

Where should an agent start reading?智能体应该从哪里开始读？

Read the repository's AGENTS.md first, then the specific skill for the task. Link the shipped skills using your agent's supported skill mechanism. Do not assume every installed daemon matches the latest client API.先阅读仓库的 AGENTS.md，再选择对应任务的技能。通过智能体支持的机制链接技能。不要假设现有守护进程一定支持最新版客户端的全部 API。
