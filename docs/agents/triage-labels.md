# Triage labels

Each triaged issue carries one category (`bug` or `enhancement`) and exactly
one state from this mapping. Other descriptive labels may remain.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation in progress |
| needs-info | needs-info | Waiting for specific reporter information |
| ready-for-agent | ready-for-agent | Verified and specified for implementation |
| ready-for-human | ready-for-human | Requires human implementation or judgment |
| wontfix | wontfix | Will not be actioned |

Read previous triage comments before changing state. Remove the previous state
when applying a new one. Conflicting existing states need maintainer direction.
Triage comments start with `> *This was generated by AI during triage.*`.
